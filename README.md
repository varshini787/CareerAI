# CareerAI

## AI-Powered Resume & Job Matching System

CareerAI is a web-based resume analysis application that compares a candidate's resume with a job description and identifies matching skills, missing skills, and overall job compatibility.

## Features

- Upload PDF resumes
- Extract text from resumes
- Detect technical skills
- Compare resume skills with job requirements
- Calculate resume-job match score
- Display matched skills
- Identify missing skills
- Provide skill improvement recommendations
- Store analysis history using MySQL
- Download analysis report
- Responsive web interface

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- PyPDF2
- python-dotenv
- Git & GitHub
